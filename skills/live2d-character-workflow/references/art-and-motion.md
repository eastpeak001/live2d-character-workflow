# 绘制、绑定和动作验收

## 一张姿势图的遮挡预算

在原始画布上保留中性参考，再把每个部件沿将要运动的最大方向移到边界。在前后两层之间露出的区域需要补画。先在底层还原连贯的线条、厚度、纹理和色温，再处理前层的抗锯齿轮廓。用浅色、深色和透明棋盘底各看一次。只在中性时看不见的缺口，最容易在转头、压腕、抬手和屈膝时露出来。

- 眼球只在眼白内移动。保留完整眼白，将虹膜、高光放在眼白范围内剪贴，独立处理上下眼睑和睫线。用全开、半闭、全闭以及重新张开的帧检查双重描边、瞳孔穿出、眼白尖角和刘海接缝。保留角色原有的嘴形。
- 以腕骨为支点给手掌留遮挡余量。书页下要有完整书封，袖口内要有袖里。重叠的手指、扣带和袖口轮廓只让一层负责最终可见的一条边。
- 分开前刘海、两侧脸旁短发、后发内层、外层长束和末梢。把发根固定在头上，让发中接到发根，发梢继承发中。挂坠绕扣环摆，蝴蝶结以结心为支点。

## 同一副骨架的三种用法

| 场景 | 先看哪里 | 关键帧与二次动作 |
| --- | --- | --- |
| 掌机 | 找到支撑脚，交叉腿有清楚的前后顺序。确定两掌在机身上的接触点。 | 另一只脚偶尔提跟落回。拇指独立按，少数强调拍才带动双臂与机身。按下时触发颜文字，眼睛回到屏幕。 |
| 棒球 | 确定两脚底、膝盖弯曲方向、双手在握把上的固定距离。 | 重心走浅弧，膝、骨盆、肩、双手依次换向。手臂经过胸口时逐帧看衣缘，腰带和裙摆各有完整底图；发梢晚一拍回正。 |
| 阅读 | 以书脊和握持点确定书与手的距离。分出上臂、袖口、手掌和书。 | 胸肩对腰形成轻微反向转动，头部稍后跟随。双手随书，又能单独调指尖。视线以书页为主，偶尔抬眼停一下再回到书。 |

## 循环的接缝

设一个周期为 N 帧，在第 0 和 N 帧记录同一姿势，导出时只取 0 到 N−1。让两端速度也能衔接。在重心上下换向时，竖向速度自然经过零；这时若肩膝和握持道具也同时静止，画面会显得卡住。把这些部位的转折略微错开，必要时让骨盆在浅弧上继续横移。按角色的重量感调整滞后，不把所有部位套进相同相位的正弦波。

将首尾前后各四帧接在一起逐帧看接缝，再按原速循环观看。标出脚尖或鞋底、膝、骨盆、锁骨、手腕、头顶、发梢的路径。先找突跳、平台或反向抽动发生在哪个点，然后只改负责该点的父级或曲线。最后重新检查眼、嘴、手指、握持处、肩袖、腰裙及活动腿覆盖区。
